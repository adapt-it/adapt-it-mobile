### What's new in Adapt It Mobile 1.19.0

- Formatted document support: this release supports the import and export of HTML and Markdown documents. As with previous releases, the focus is on translating the text itself — formatting markers are not used to display the text in the editor, but are instead preserved and inserted into the exported document. (#622, #624, #625, #633, #634)
- Android: added support for newer devices with a 16KB page size (#630)
- Android: added F-Droid App Store repository descriptions for the following locales: es, pt, fr, ru (#637, #638)

Bug fixes:
- Fixed an issue where the Export action was not displayed at app launch (#631)

You can find more information about these changes in our issue tracker: https://github.com/adapt-it/adapt-it-mobile/milestone/67?closed=1.

Need help getting started with Adapt It Mobile? Our user site (https://adapt-it.github.io/adapt-it-mobile/getstarted/) has instructions to help you install and configure your project. We also have training videos available on Vimeo here: https://vimeo.com/showcase/11035505
If you have an issue to report or an enhancement request to share, you can contact us via our issues page: https://github.com/adapt-it/adapt-it-mobile/issues
